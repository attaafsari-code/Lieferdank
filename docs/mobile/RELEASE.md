Die App-Basisadresse ist im EAS-Production-Profil korrekt `https://lieferdank.de`; kein ATS-/TLS-Workaround wurde eingebaut. Die neue Fehlerbehandlung unterscheidet eine fehlende/ungültige Serverantwort von einer tatsächlichen Netzwerkstörung.
